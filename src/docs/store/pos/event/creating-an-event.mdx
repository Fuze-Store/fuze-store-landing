# 📝 How to Create an Event (Appointment or Reservation)

<br />

Creating an event in Fuze Store POS is quick and easy! Whether you’re booking an appointment for a service or reserving a space, just follow these simple steps.

<br />

## ✨ What You Can Create

- **Appointment:** Book a service or product for a customer (like a haircut, massage, or class).
- **Reservation:** Reserve a table, room, or space (like in a restaurant or hotel). You can add services/products if you want, but it’s not required.

<br />

## 📍 Step-by-Step Guide

1. **Open the Menu:** Click the **☰ sidebar hamburger menu** to open navigation.
2. **Go to POS Event:** Select **POS Event** from the menu list.
3. **Create Event:** Click **“Create Event”** button at the top right.
4. **Choose the type:**
   - Select **Appointment** if you’re booking a service or product (required).
   - Select **Reservation** if you’re reserving a space (services/products optional).
5. **Fill in the details:** Fill in any details you need. See [Event Overview](/docs/store/pos/event/overview) for more information.
6. **Save the event:** Click **Save Change** to create your event.

<br />

## 💡 Tips

- Appointments always need a service or product. Reservations don’t—add them only if you want.
- When you create an appointment, an order is made automatically for easy checkout.
- Double-check the date and time to avoid double-booking.
- Use clear names and notes so everyone knows what’s booked.
- You can edit or cancel events anytime if plans change.
