# ✏️ How to Update an Event (Appointment or Reservation)

<br />

Need to make a change to a booking? No problem! Fuze Store POS makes it easy to update any event, whether it’s an appointment or a reservation.

<br />

## 📍 Step-by-Step Guide

1. **Open the Menu:** Click the **☰ sidebar hamburger menu** to open navigation.
2. **Go to POS Event:** Select **POS Event** from the menu list.
3. **Select Event:** In Event list or calendar page, find the event you want to update.
4. **Event Details:** Click on the event to open its details.
5. **Edit Event:** Click **“Edit”** or the pencil icon.
6. **Update Event Details:** Update any details you need. See [Event Overview](/docs/store/pos/event/overview) for more information.
7. **Save your changes.** That’s it—the event is updated!

<br />

## 💡 Tips

- Double-check the new date and time to avoid conflicts.
- If you remove all services/products from an appointment, it will no longer be valid—appointments always need at least one.
- For reservations, you can add or remove services/products as needed.
- Use notes to keep everyone on the same page.
- Customers can be notified of changes if you have reminders set up.
