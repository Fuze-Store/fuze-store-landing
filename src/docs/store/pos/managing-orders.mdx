# 🛒 Managing Orders in the POS Register

<br />

Managing orders in the POS Register is easy and flexible, so you can keep track of your current orders. No technical skills needed! This guide will show you the key features and simple steps for handling orders from start to finish.

<br />

## ✨ Key Features for Managing Orders

<br />

- **List all of your current Orders:** You will see a list of all your current orders, including their status and details grouped by their status (Pending, On-Hold, Processing, Ready, Shipped, Complete).
- **View Order Details:** View detailed information about each order, including items, quantities, prices, and customer information.
- **Full Action Buttons:** You can perform actions like editing, voiding, or refunding orders directly from the order details.
  - **Note:** List of actions available may vary based on current order status, store permissions, and your user role.

<br />

## 📝 How to Use the Managing Orders Page (Step-by-Step)

<br />

1. **Open the Menu:** Click the **☰ sidebar hamburger menu** to open navigation.
2. **Go to POS Orders:** Click the **POS Orders** from the main menu. You’ll see all your current orders, grouped by their status (Pending, On-Hold, Processing, Ready, Shipped, Complete).
   - If the store has session enabled and not started, you will be prompted to start a new session.
   - If the store has session enabled and already started or the session is disabled, you will be taken directly to the POS.
3. **Select an Order:** Click on any order to view its details, including items, prices, customer info, and order history.
4. **Take Action:** Use the action buttons to edit, void, refund, update, etc to change the order status as needed.
   - Actions available may depend on the order’s current status and your permissions.

<br />

## List of Actions

<br />

| Action                  | What It Does                                                 |
| ----------------------- | ------------------------------------------------------------ |
| **Accept Order**        | Accept the incoming order.                                   |
| **Cancel Order**        | Cancel the order if it’s not completed yet.                  |
| **Notify**              | Send notifications to customers thru email or mobile number. |
| **Print Slip**          | Print the order slip for the customer.                       |
| **Print Receipt**       | Print the order receipt for the customer.                    |
| **Edit Order**          | Modify items, quantities, or prices in the order.            |
| **Void/Close Order**    | Void the order if it’s completed and needs to be closed.     |
| **Process Order**       | Change order status to **Processing**                        |
| **Hold Order**          | Change order status to **On-Hold**                           |
| **Pending Order**       | Change order status to **Pending**                           |
| **Ready Order**         | Change order status to **Ready**                             |
| **Ship Order**          | Change order status to **Shipped**                           |
| **Complete Order**      | Change order status to **Completed**                         |
| **Add Payments**        | Add payments to the order.                                   |
| **Apply Gift Cards**    | Apply gift cards to the order.                               |
| **Update Service Mode** | Change the service mode for the order.                       |
| **Assign Staffs**       | Assign staff members to the order.                           |

## 💡 Tips

- Always double-check the order details before accepting or processing.
- If you make a mistake, you can void or refund the order.
- Attach customers to orders for loyalty rewards and easier returns.
- Assign staff to orders for better tracking and reporting.
- Add notes for special requests or delivery instructions.
