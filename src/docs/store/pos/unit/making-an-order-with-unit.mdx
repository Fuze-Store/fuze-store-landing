# 📝 How to Make an Order with Unit

<br />

Assigning an order to a specific table, room, or seat in Fuze Store POS is easy! This helps your team know exactly where each order belongs and keeps your business running smoothly.

<br />

### 📍 Step-by-Step Guide

1. **Open the Menu:** Click the **☰ sidebar hamburger menu** to open navigation.
2. **Go to POS Unit:** Click the **POS Unit** from the main menu.
3. **Select a Unit:** Choose the unit (e.g. table, room, seat, or space) where the order will be served. (For example: Table 5, Room 2, Seat 8.)
4. **Create Order:** Follow [How to Use the POS Register/Terminal](docs/store/pos/using-pos-register) on how to create a new order.
5. **Success:** The unit will be automatically assigned to the order you create.

That’s it! The order is now linked to the unit you selected, so everyone knows where it should go.

<br />

## 💡 Tips

- Always double-check you’ve selected the right unit before saving the order.
- Use clear names or numbers for your units (like “Table 3” or “Booth 1”) so staff don’t get confused.
- You can move an order to a different unit later if needed (for example, if a customer changes tables).
- Assigning orders to units helps you track which areas are busy and plan your service better.
