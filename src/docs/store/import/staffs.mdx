# 🎛️ Importing Staffs

<br />

Moving your data in or out of Fuze Store POS is easy! Whether you want to back up your information, switch systems, or update your products in bulk, you can import or export your store data in just a few steps—no technical skills needed.

<br />
<br />

## 📍 Step-by-Step Guide

1. **Open the Menu:** Click the **☰ sidebar hamburger menu** to open navigation.
2. **Go to Store:** In **Store** section, select **Store** from the menu list.
3. **Go to Import:** In **Store** screen, select **Import** from the list.
4. **Fill Form:**
   - In the "Type" field, choose **Staffs** from the dropdown menu.
   - In the "File" field, upload your file (CSV or Excel format).
     > See sample [Sample Staffs.xlsx](#) for reference.
5. **Import:** Click on **Import** button. Your data will be added to your store.

<br />

## ⚙️ Field Explanations

<br />

Here are the columns structure of the Staffs import file:

<br />

| Field          | Description                                                                | Required | Possible Values | Example                                         |
| -------------- | -------------------------------------------------------------------------- | -------- | --------------- | ----------------------------------------------- |
| **id**         | Unique uuid identifier for the staff (Empty field will create a new staff) |          |                 | 123e4567-e89b-12d3-a456-426614174000            |
| **role_id**    | uuid or code identifier of the role                                        |          |                 | 123e4567-e89b-12d3-a456-426614174001 or barista |
| **first_name** | First name of the staff                                                    | **Yes**  |                 | John                                            |
| **last_name**  | Last name of the staff                                                     | **Yes**  |                 | Doe                                             |
| **email**      | Email address of the staff                                                 |          |                 | john.doe@email.com                              |

<br />
<br />

## 💡 Tips

- Always double-check your data before importing to avoid mistakes.
- If you’re not sure about the file format, download a sample export first.
- If you need help, contact support or check the Help Center.
- Keep your staff structure organized for easier management.
- Use clear and descriptive names for your staffs.
- Regularly review and update your staffs as needed.
