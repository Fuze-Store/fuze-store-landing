## ➕ How to Add a Category

<br />
Organizing your products and services with categories makes it easier for staff
and customers to find what they need. Categories can be things like "Drinks",
"Snacks", or "Packages"—whatever fits your business best. You don’t need any
technical skills to add a new category!
<br />
<br />

### 📍 Step-by-Step Guide

<br />

1. **Open the Menu:** Click the **☰ sidebar hamburger menu** to open navigation.
2. **Go to Categories:** Select **Categories** from the menu list.
3. **Add a Category:** Press the **Add Category** button (usually at the top right).
4. **Fill in the Details:** Enter the information for your new category (see below for what each field means).
5. **Save Changes:** Click **Save**. Your updates will appear instantly in your POS and menus.

<br />

### ⚙️ Field Explanations

<br />

| Field                            | What it Means                                         | Required | Example                             |
| -------------------------------- | ----------------------------------------------------- | -------- | ----------------------------------- |
| **Name**                         | The name people see in the app and menus.             | **Yes**  | Massage Therapy                     |
| **Active**                       | Turn on if you want this category to be available now |          |                                     |
| **Include in Menu**              | Show this category in your POS and digital menus      |          |                                     |
| **Code** _(optional)_            | Short code for internal use (usually auto-filled)     |          | massage-therapy                     |
| **Description** _(optional)_     | A short note about what’s in this category            |          | Relaxing massages for stress relief |
| **Color** _(optional)_           | Pick a color to help organize or highlight categories |          | #FF5733                             |
| **Image** _(optional)_           | Upload a picture or icon for the category             |          |                                     |
| **Parent Category** _(optional)_ | Choose if this is a sub-category of another category  |          | Massage                             |

<br />
<br />

### 💡 Tips

- Make sure the **Category Name** is unique and easy to understand.
- Codes should not have spaces (e.g. use `hot-drinks`).
- Use categories to help organize items in your POS and make searching easier.
- Add images and colors to make categories stand out for staff and customers.
- You can always edit or remove categories later if your offerings change.
