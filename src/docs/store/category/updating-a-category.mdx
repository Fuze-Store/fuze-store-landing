# 📝 How to Update a Category

<br />

Keeping your categories up to date ensures your POS and menus always reflect your current offerings. This guide will help you easily edit any category, whether you want to change its name, color, image, or other details—no technical skills required!

<br />
<br />

## 📍 Step-by-Step Guide

1. **Open the Menu:** Click the **☰ sidebar hamburger menu** to open navigation.
2. **Go to Categories:** Select **Categories** from the menu list.
3. **Choose a Category:** In Category list page, Click the category you want to edit (for example, `Drinks`).
4. **Edit Details:** Update any of the fields below as needed (see [Field Explanations](/docs/store/category/overview#-field-explanations) for what each field means).
   - **Enable:** Keep this category active and visible in the app (default is `Yes`).
   - **Include in Menu:** Enable this if you want to show this category in your POS and digital menus (default is `Yes`).
   - **Category Name:** The name people see in the app and menus (e.g., `Drinks`).
   - **Code:** A short code for internal use (e.g., `drinks`).
   - **Parent Category:** Choose if this is a sub-category of another category (optional).
   - **Description:** A brief note about what’s in this category (e.g., `All types of beverages`).
   - **Color:** Pick a color to help organize or highlight this category (e.g., `#FF5733`).
   - **Image:** Upload an image or icon for the category (optional).
5. **Save Changes:** Click **Save**. Your updates will appear instantly in your POS and menus.

<br />
<br />

## 💡 Tips

- You can update categories anytime—changes show up right away.
- Use clear names and images so staff and customers can find things easily.
- Use colors to make important categories stand out.
- If you’re not sure about a field, you can leave optional ones blank.
