# 💳 How to Set a Default Payment Method for Your Account

<br />

Setting a default payment method makes paying for your Fuze Store POS subscription quick and worry-free. Your default card or payment option will be used automatically for future payments. No technical skills needed! This guide will show you how to set it up in just a few steps.

<br />

## 📍 Step-by-Step Guide

<br />

1. **Open the Menu:** Click the **☰ sidebar hamburger menu** to open navigation.
2. **Go to Account:** Select **Account** from the menu.
3. **Go to Subscription:** Select **Subscription** from the list.
4. **Find Payment Methods:** Under **Payment Methods** section, select payment methods you want to remove.
5. **Set as Default:** Click **Set as Default**.
6. **Save:** Your default payment method will be updated and used for future payments.

<br />

## 💡 Tips

- Make sure your default payment method is up to date to avoid payment issues.
- You can change your default payment method anytime.
- If your default card expires or is replaced, update it right away.
- If you have questions or need help, contact support.

<br />

For more help, see the documentation or contact support.
